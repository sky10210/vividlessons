How classroom access will work

1. Teacher purchases one module. 2. A classroom code is issued after verified payment. 3. The teacher activates the code and shares it with students. 4. Students complete the module and save their certificates. 5. Access expires 30 days after activation.

This page is a nonfunctional checkout mockup. Paid lesson protection, Stripe webhooks, access-code validation, and certificate testing must be completed before launch.
